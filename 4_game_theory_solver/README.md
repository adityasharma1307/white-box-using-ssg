# Phase 4: Game Theory Solver (Stackelberg Equilibrium)

**Contributor:** Aditya Sharma (The Game Theorist)

## Overview
This directory contains the mathematical engine of the project. To overcome the computational constraints of performing deep internal mechanistic interpretability on billions of parameters, we formalize the LLM auditing process as a **Stackelberg Security Game (SSG)**. 

## Methodology
Using the empirical detection rates ($Q$ matrices) generated by the White-Box Auditor in Phase 3, we compute the Strong Stackelberg Equilibrium (SSE). Because continuous punishment variables introduce non-convex constraints, standard optimization fails. We bypass this by employing a Multiple Linear Programs (Multiple-LP) approach using the `cvxpy` library.

For the final analysis, we run a comparative solver to evaluate the dual-track framework:
1. **Track A (De Novo Injection):** Hunting a synthetic backdoor.
2. **Track B (Latent Amplification):** Hunting an amplified pre-existing bias.

By solving both games, we generate the optimal randomized auditing policies ($p^*_A$ and $p^*_B$). This allows us to definitively answer whether a computationally constrained auditor must dynamically shift their layer-inspection strategy based on how the covert poison was originally injected.

## Directory Contents
* `ssg_solver.py` - The core `cvxpy` Multiple-LP solver class.
* `dual_track_analyzer.py` - The comparative wrapper that evaluates Track A vs. Track B simultaneously.
* `/results/` - Contains the final output probability arrays and mathematical conclusions used in the final paper.
